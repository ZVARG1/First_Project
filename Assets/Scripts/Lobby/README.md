# Lobby

## Purpose

Contains all systems used inside the multiplayer social hub.

## Scripts

### HangarIntroManager

Shows splash screen before entering the lobby.

### LobbyAvatarController

Controls local player movement.

### LobbyUIManager

Controls ESC menu, teleports and player interaction.

### MainMenuController

Controls hosting/connecting to lobbies (SUBJECT TO CHANGE)

## Flow

Splash Screen -> Host Lobby -> Spawn Avatar -> Free Movement -> Mission Selection
